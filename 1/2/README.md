## Задача 2. Ada — производитель-потребитель с ограниченным буфером
**Постановка:** реализовать паттерн "производитель-потребитель" с общей очередью фиксированного размера. Несколько потоков-производителей генерируют данные, несколько потоков-потребителей их обрабатывают. Необходимо обеспечить синхронизацию: производитель не помещает данные в полную очередь, потребитель не извлекает данные из пустой.
