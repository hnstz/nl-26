## Задача 3. Elixir — об обедающих философах с предотвращением взаимной блокировки
**Постановка:** Пять философов сидят за круглым столом. Перед каждым — тарелка, между каждой парой соседних философов — вилка. Философы чередуют два состояния: размышление и еду. Чтобы есть, философу нужны обе вилки — левая и правая. После еды вилки возвращаются на стол.
Классическая проблема: если каждый философ возьмёт левую вилку и будет ждать правую — возникнет взаимная блокировка.
